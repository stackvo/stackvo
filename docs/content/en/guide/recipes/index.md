# Recipes

One page per kind of project, from nothing to a first request answered at
its own address. Each recipe uses the same three moves — create, add what it
needs, run — and names the cards and commands that matter for that stack.

<div class="grid cards" markdown>

- :simple-laravel: **[Laravel](laravel.md)**

    ---

    The template, a database, migrations, the queue worker, Mailpit for
    mail, Octane if you use it.

- :simple-wordpress: **[WordPress](wordpress.md)**

    ---

    The template, MySQL, WP-CLI from the terminal, and the plugin or theme
    you are actually working on.

- :simple-nodedotjs: **[Node.js](nodejs.md)**

    ---

    Next.js, Nuxt, Vite and the rest: the install, build and start
    commands, and the dev server with your source mounted live.

- :simple-python: **[Python](python.md)**

    ---

    Django, Flask and FastAPI: the start command, a database, and the
    packages you install.

</div>

A stack not on this list — Go, Ruby, Rust, Bun, Deno, or a framework without
a template — is an [empty project](../projects.md) with a runtime picked from
the catalogue and a start command. The moves are the same.
