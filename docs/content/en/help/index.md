# In-app help

Every card on the project page and the settings page — and every page itself —
carries a **?** button in the corner. It opens a panel beside the card, not
over it, explaining what the card is for and what each control in it does:
what gets written, what gets restarted, whether the change survives a rebuild.

The documents behind those buttons are published here, grouped the way the
application groups them. They are the same files, read from the same place —
the running app fetches them from this repository the first time a topic is
opened, so a correction reaches the window and this site together.

Each document has the same shape:

- **What it is** — one or two sentences, and what it is not.
- **Controls** — every button and field, and what pressing it actually does.
- **Worth knowing** — the things somebody finds out the hard way: what has to
  be running, what silently does nothing, what costs money or exposes
  something.
