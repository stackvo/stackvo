# Workspace directory

The checkout this application manages. Projects, generated files and `.env` live here.

## Controls

| Control | What it does |
| --- | --- |
| Choose a folder | Switches to another workspace. |
| Open the folder | Reveals the directory in Finder or Explorer. |

## Worth knowing

- Switching workspaces changes everything the app sees: projects, services, settings. Nothing in the old directory is deleted.
- A directory has to have the structure StackVo recognises. If it does not, the app says so rather than switching.
