# Composition

The inside of the measurements above. The total says how much is being used; this says what it is being used on.

## The rings

| Ring | What it shows |
| --- | --- |
| Memory | Memory the container is using, against its limit. |
| Network | The ratio of traffic in to traffic out. |
| Disk I/O | The ratio of reads to writes. |

The raw numbers are written under each ring.

## Worth knowing

- If the project is stopped there is nothing to draw, and the card says so.
- The numbers are totals accumulated since the container started, not a current rate. Restarting resets them.
