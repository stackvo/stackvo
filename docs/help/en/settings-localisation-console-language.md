# Console language

The language of the log and terminal panels. Independent of the interface language.

## Controls

| Control | What it does |
| --- | --- |
| Console language | Picks the language for the console panels. **Same as the interface** follows the interface language. |

## Why it is separate

When you paste error output to a colleague or into a bug report, English is useful. You can keep the interface in your own language and leave the console in English.

## Worth knowing

- This only affects the app's own text. Lines written by the container are whatever they are.
