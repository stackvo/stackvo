# Typography and legibility

Typeface, interface scale and contrast.

## Controls

| Control | What it does |
| --- | --- |
| Typeface | The interface font. Only faces installed on this system are listed. |
| Interface scale | The base font size. Everything scales with it. |
| Interface density | Tight, comfortable or spacious. Row heights and button sizes change. |
| High contrast | Strengthens secondary text and dividers. |
| Reduce motion | Turns transitions off. Progress indicators keep spinning. |

## Worth knowing

- Density changes spacing only, not text size. Use the two together.
- High contrast increases the difference between text and background; it does not change the colours.
