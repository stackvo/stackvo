# Theme and colours

How the app looks. Changes apply immediately and are remembered.

## Controls

| Control | What it does |
| --- | --- |
| Theme | System, light or dark. On System it follows your operating system. |
| Accent colour | The highlight colour. Buttons, selected rows and links use it. |
| System accent | Uses the operating system's own accent colour. |
| Neutral palette | The tone of the backgrounds and surfaces. |
| Corner radius | The corner rounding of cards and buttons. |
| Defaults | Puts everything on this card back to its starting value. |

## Worth knowing

- These are stored on this machine only. Nothing is written to the workspace or your projects.
- If you like a look, name and save it on the Presets card.
