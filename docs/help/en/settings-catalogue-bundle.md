# Bundle

The installed catalogue versions, and local package operations.

## Controls

| Control | What it does |
| --- | --- |
| Save a bundle | Writes the current catalogue to a single file. |
| Load a bundle | Reads a saved catalogue bundle into this machine. |

## What it is for

Carrying a catalogue to a machine with no internet access. Save the bundle on one machine, load it on the other.

## Worth knowing

- The bundle is the catalogue itself; it does not contain images. Services still pull their images the first time they run.
- An administrator can pin the source to a bundle. Then the address setting is ignored.
