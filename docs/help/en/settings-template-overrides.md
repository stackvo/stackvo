# Template overrides

Templates are built into the app. A file only appears in the workspace when you take it over.

## Controls

| Control | What it does |
| --- | --- |
| Template to take over | Which template to override. |
| Take over and edit | Copies the file into the workspace and opens it in your editor. |
| Open | Opens an overridden file in your editor. |
| Revert to default | Deletes the overridden file; the built-in version takes over again. |
| Reload | Reads the list again. |

## What taking one over costs

From the moment you take a template over, app updates stop reaching that file. Fixes in later versions do not arrive in your copy.

## Worth knowing

- Reverting cannot be undone. The file you edited is deleted and there is no other copy.
- The card shows how many templates exist and how many are overridden.
