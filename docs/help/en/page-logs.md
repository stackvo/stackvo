# Logs

Every project's output in one stream. For one project's own logs, see that project's Logs tab.

## What this page is for

A project page answers "what did this project write". This answers the question you have before that: "which of my eight projects just errored?"

It is a page to leave open; lines accumulate here while you work in another window.

## Worth knowing

- It is live only. Only output written after the page opened appears here.
- To read the history of a file, open the project; its source picker offers the log files too.
