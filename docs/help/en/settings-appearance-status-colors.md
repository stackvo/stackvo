# Status colours

Which colours say running, stopped and failed.

## Controls

| Control | What it does |
| --- | --- |
| Palette | Default (green/red), colourblind-safe (Okabe-Ito) or muted. |
| Keep consoles dark | Log and terminal panels stay dark in the light theme. |

## Worth knowing

- The colourblind-safe palette does not rely on a red-green distinction. Status is also carried by an icon, so colour is never the only signal.
- The dark console setting affects the output area only; the toolbar above it stays in the page's theme.
