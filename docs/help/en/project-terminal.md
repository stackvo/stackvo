# Terminal

A shell inside this project's container, in this window. Same container, same paths, the same environment your application sees.

## Controls

| Control | What it does |
| --- | --- |
| Open a shell | Starts the session. |
| Close | Ends the session and the process behind it. |

## The difference between the two terminals

| | This card | "Open a terminal" in the top bar |
| --- | --- | --- |
| Opens in | The app window | Your own terminal application |
| Your profile | No | Yes |
| Suits | The twenty seconds you spend checking a path | Work you will stay in |

## Worth knowing

- The project has to be running. There is nothing to attach to in a stopped container.
- The card does not open a shell on its own; you have to press the button.
- Closing the card or leaving the page ends the session.
