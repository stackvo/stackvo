# Dumps

Every project's `dump()` and `dd()` output in one list. For one project's own dumps, see that project's Debugging tab.

## What this page is for

A project pane answers "what did this project dump". This answers the question before that: "which of my eight projects just dumped something?"

It also closes a gap. Capture stays on across pages, so a dump from a queue worker or a console command is caught while you are looking somewhere else. This is where those events accumulate.

## Worth knowing

- Nothing accumulates while capture is off. Turn it on in the toolbar.
- Capture is per project. The toolbar says how many projects are capturing.
