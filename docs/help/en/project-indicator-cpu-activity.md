# CPU Activity

CPU use hour by hour over recent days. Each square is one hour: dark green is little, light green is a lot.

## Worth knowing

- Samples are taken once a minute. Nothing is sampled while the app is closed.
- An hour with no sample looks different from an hour that measured zero. An empty square means "no data", not "never used".
- Hovering an hour shows its value.
- With no history yet the card says so. It stays empty until the first samples accumulate.
