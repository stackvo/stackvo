# Health

The total number of containers in this workspace, how many are running and how many are stopped.

## The numbers

| Number | What it covers |
| --- | --- |
| The large figure | Total containers: projects and services together. |
| Running | The ones up right now. |
| Stopped | Containers that exist but are not running. |

## Worth knowing

- The count is read from the engine. A container stopped in another window shows as stopped here too.
- A project that has never been built is not counted; it has no container yet.
