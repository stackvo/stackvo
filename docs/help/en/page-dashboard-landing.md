# Landing page

One page listing every project and service, on this workspace's own address. This is the address to bookmark or hand to the team.

## Controls

| Control | What it does |
| --- | --- |
| Publish | Starts the sidecar container that serves the page. |
| Stop | Takes it down; the address stops answering. |
| Rewrite | Regenerates the page with the current list of projects and services. |
| Clicking the address | Opens the page in your browser. |

## Worth knowing

- The page does not update itself. It shows the list as it was when it was started or rewritten, and the card says when that was.
- After adding a project you have to press **Rewrite**.
