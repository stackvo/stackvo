# System information

What a bug report needs: the app version, the operating system, the Docker version and context, and the workspace path.

## Controls

| Control | What it does |
| --- | --- |
| Copy | Puts the whole block on the clipboard. |

## Worth knowing

- Copy rather than retype. A version number transcribed wrong makes a bug report useless.
- For a fuller report use **Save a diagnostics bundle** on the Application log card. That puts the log, the preflight checks and the doctor report beside this information.
