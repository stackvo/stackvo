# Gelen kutusu

Yakalanan postalar. Soldan bir mesaj seçin, sağda okuyun.

## Liste

| Kontrol | Ne yapar |
| --- | --- |
| Ara | Mesajları süzer. `from:ali@ornek.com` ya da `subject:"fatura"` yazabilirsiniz. |
| Yenile | Listeyi yeniden okur. |
| Gelen kutusunu boşalt | Yakalanmış tüm mesajları siler. |

Liste başlığında kaç mesajın yakalandığı, kaçının okunmadığı ve aramanız kaç tanesiyle eşleştiği yazar.

## Mesaj sekmeleri

| Sekme | Ne gösterir |
| --- | --- |
| Önizleme | HTML gövde, yalıtılmış bir çerçevede. |
| Metin | Düz metin gövde. |
| Kaynak | Ham mesaj. |
| Başlıklar | Tüm başlıklar. |
| Ekler | Eklenen dosyalar; kaydedebilirsiniz. |
| Uyumluluk | Kullanılan HTML ve CSS özelliklerinin posta istemcilerinde desteklenip desteklenmediği. Yeşil tam destek, turuncu kısmi, kırmızı desteklenmiyor. |
| Bağlantılar | Mesajdaki bağlantılar. **Bağlantıları denetle** her birini çeker. |

## Gönder

Bir mesajı gerçek bir adrese iletir. Kopyası yakalayıcıda kalır.

Bunun için Aktarım sunucusu ayarlanmış olmalıdır. Aktarım, yalnızca sizin ilettiğiniz mesajı dışarı çıkarır; uygulamanızın gönderdikleri yakalanmaya devam eder.

## Bilinmesi gerekenler

- HTML gövde yalıtılmış bir çerçevede gösterilir. Yakalanan bir posta, test ettiğiniz kodun gönderdiği her şey olabilir.
- **Bağlantıları denetle** işlemi makinenizin dışına çıkar; her bağlantı gerçekten çekilir.
- Aktarım parolası işletim sisteminin kasasında saklanır ve bir daha gösterilmez.
- Aktarımda "yalnızca şuraya gönderilebilsin" listesini boş bırakmak "her yere" demektir. Bu, tek yazım hatası uzaklıktadır.
