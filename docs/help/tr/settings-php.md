# PHP ve web sunucusu

Yeni bir PHP projesinin başlangıç değerleri. Var olan projeler kendi `stackvo.json` dosyasındaki sürümü korur.

## Kontroller

| Kontrol | Ne yapar |
| --- | --- |
| PHP sürümü | Yeni proje formunda önceden seçili gelir. Her proje yine kendi sürümünü seçebilir. |
| Web sunucusu | PHP projelerini sunacak sunucu: nginx, Apache, Caddy, FrankenPHP ya da Swoole. |

## Bilinmesi gerekenler

- Buradaki değişiklik yalnızca bundan sonra kurulacak projeleri etkiler. Var olan bir projenin sürümünü değiştirmek için o projenin sayfasına gidin.
- Diğer çalışma zamanları kendi geliştirme sunucusunu çalıştırır; bu ayar onları etkilemez.
