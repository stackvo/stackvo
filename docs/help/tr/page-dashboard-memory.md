# Bellek

Bu makinenin bellek kullanımı: kullanılan ve boş.

## Bilinmesi gerekenler

- Bu, makinenin tamamının belleğidir. Docker'ın kendisine ayrılan bellek de içindedir.
- Docker Desktop kullanıyorsanız konteynerler bir sanal makinenin içinde çalışır. O sanal makinenin sınırı Docker'ın kendi ayarlarındadır; buradaki sayı sınırı değil, kullanımı gösterir.
- Tek bir projenin bellek kullanımı için o projenin Gösterge sekmesine bakın.
